# Scrum na Biblioteca — Atividades 01 a 04

Resolução das quatro atividades em trio de Engenharia de Software sobre Scrum usando o aplicativo fictício de **reserva de salas de estudo da biblioteca**.

**Alunos:** Daniel Alves · Kaio Costa · Francisco Breno

## O que tem no repositório

- `index.html`, `style.css`, `script.js`: página web simples com as respostas das 4 atividades, protótipos interativos e testes clicáveis.
- `RESPOSTAS_ATIVIDADES.md`: versão em texto pronta para entrega.

## Atividades resolvidas

1. **Atividade 01 — Introdução ao Scrum:** consulta da Sala 1 em duas rodadas (da resposta em branco à mensagem clara de "Ocupado") e respostas sobre Transparência, Inspeção, Adaptação e Abertura.
2. **Atividade 02 — Papéis, Artefatos e Eventos:** Product Backlog, Sprint Backlog ajustado na Reunião Diária, protótipo de reserva (Teste A e Teste B), Revisão e Retrospectiva.
3. **Atividade 03 — Product Owner:** primeira priorização (5 atrasos), repriorização com fato novo (8 reservas sem uso) e demonstração de cancelar reserva.
4. **Atividade 04 — Scrum Master:** encaminhamento do impedimento da conta sem acesso, mensagem ao suporte, plano ajustado entre o que dá para fazer hoje e o que depende do suporte amanhã, e simulação do ambiente de teste.

## Como abrir

Basta dar um duplo clique no arquivo `index.html` no navegador. Não precisa instalar nada.

## Como subir para o Git e publicar no GitHub Pages

```bash
git init
git add .
git commit -m "feat: resolucao das atividades 01 a 04 de Scrum"
git branch -M main
git remote add origin https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
git push -u origin main
```

Depois, no GitHub: **Settings → Pages → Branch `main` / `/ (root)` → Save**.
